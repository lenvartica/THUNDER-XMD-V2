# Commands

| Command | Permission | Description |
|---|---|---|
| /help | Public | Lists registered commands |
| /menu | Public | Alias of help |
| /ping | Public | Checks bot response |
| /runtime | Public | Shows uptime |
| /status | Public | Shows connection state |
| /owner | Public | Shows configured owner |
| /about | Public | Shows project identity |
| /settings | Owner | Shows safe settings |
| /restart | Owner | Requests controlled shutdown |
| /groupinfo | Group | Shows group metadata |
| /tagall | Group admin | Mentions group participants |
